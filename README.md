# EPS-DTI
Integrating Expert Priors with Dual-Level Contrastive Repre-sentation Learning for Data-Efficient Drug Discovery
# Explanation
This project is the code for the paper "EPS-DTI: Expert-prior-guided dual-level contrastive learning for drug–target interaction prediction" submitted to the *Journal*. We have uploaded some of the data and code; the remaining code will be uploaded in full after the paper is accepted.
