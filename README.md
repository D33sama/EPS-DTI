# EPS-DTI
Integrating Expert Priors with Dual-Level Contrastive Repre-sentation Learning for Data-Efficient Drug Discovery
# Explanation
This project is the code for the paper "EPS-DTI: Expert-Prior-Guided Dual-Level Contrastive Learning for Drug–Target Interaction Prediction" submitted to the *AAAI 2027*. We have uploaded some of the data and code; the remaining code will be uploaded in full after the paper is accepted.
